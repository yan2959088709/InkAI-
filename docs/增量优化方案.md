## 3. 增量优化步骤

### Step 1: 集成 NarrativeStateMonitor (低风险)

**目标**: 添加剧情状态监控，不改变现有流程

**集成方式**:
```python
# 在 InkAIWorkflowOptimized 中添加
class InkAIWorkflowOptimized:
    def __init__(self):
        # 现有初始化代码...

        # 新增: NarrativeStateMonitor (桥接模式)
        from core.narrative_state_monitor import NarrativeStateMonitor
        self.narrative_monitor = NarrativeStateMonitor(
            novel_id=self.novel_id,
            data_manager=self.data_manager
        )
```

**验证方法**:
- 运行现有小说续写功能
- 检查新组件的日志输出
- 确保原有功能不受影响

**风险**: 低 - 仅添加新组件，不修改现有逻辑

---

### Step 2: 集成 EnhancedContextBuilder (中风险)

**目标**: 替换上下文构建策略，但保留原Selector

**集成方式**:
```python
# 添加桥接配置
ENABLE_ENHANCED_CONTEXT = False  # 默认关闭

# 在 IntelligentContextSelector 中添加
class IntelligentContextSelector:
    def __init__(self, ...):
        # 现有初始化代码...

        # 新增: EnhancedContextBuilder
        if ENABLE_ENHANCED_CONTEXT:
            from core.enhanced_context_builder import EnhancedContextBuilder
            self.enhanced_builder = EnhancedContextBuilder(
                data_manager=self.data_manager,
                narrative_monitor=self.narrative_monitor
            )

    def select_context(self, ...):
        if ENABLE_ENHANCED_CONTEXT and self.enhanced_builder:
            return self.enhanced_builder.build_context(...)
        return self._legacy_select_context(...)
```

**验证方法**:
- 关闭开关时，原功能正常
- 开启开关时，新上下文策略生效
- 对比两种策略的效果

**风险**: 中 - 可能影响上下文质量

---

### Step 3: 简化Agent架构 (高风险)

**目标**: 将27个Agent简化为2-3个核心Agent

**策略**: 渐进式合并
1. 先将评估Agent合并
2. 再将改进Agent合并
3. 最后考虑Writer合并

**验证方法**:
- 每步合并后运行测试
- 对比简化前后的生成质量

**风险**: 高 - 可能影响生成质量

## 4. 桥接层设计

### 4.1 桥接配置

```python
# config_optimization.py

OPTIMIZATION_CONFIG = {
    "step1_narrative_monitor": {
        "enabled": False,  # Step 1: 默认关闭
        "monitor_only": True,  # 只监控，不干预
    },
    "step2_enhanced_context": {
        "enabled": False,  # Step 2: 默认关闭
        "strategy": "max_context",  # 可选: max_context, key_fragment, hybrid
        "fallback_to_legacy": True,  # 失败时回退
    },
    "step3_simplified_agents": {
        "enabled": False,  # Step 3: 默认关闭
        "parallel_mode": True,  # 新旧Agent并行运行对比
    }
}
```

### 4.2 桥接类

```python
# core/optimization_bridge.py

class OptimizationBridge:
    """
    优化桥接层

    职责:
    1. 管理新组件的启用/禁用
    2. 提供统一的接口
    3. 处理回退逻辑
    """

    def __init__(self, legacy_workflow, config):
        self.legacy = legacy_workflow
        self.config = config

        # 新组件 (按需初始化)
        self.narrative_monitor = None
        self.enhanced_context = None
        self.simplified_agent = None

    def initialize_step1(self):
        """初始化Step 1组件"""
        if self.config["step1_narrative_monitor"]["enabled"]:
            from core.narrative_state_monitor import NarrativeStateMonitor
            self.narrative_monitor = NarrativeStateMonitor(
                novel_id=self.legacy.novel_id,
                data_manager=self.legacy.data_manager
            )

    def initialize_step2(self):
        """初始化Step 2组件"""
        if self.config["step2_enhanced_context"]["enabled"]:
            from core.enhanced_context_builder import EnhancedContextBuilder
            self.enhanced_context = EnhancedContextBuilder(
                data_manager=self.legacy.data_manager,
                narrative_monitor=self.narrative_monitor,
                default_strategy=self.config["step2_enhanced_context"]["strategy"]
            )

    def get_context(self, novel_id, chapter_num, ...):
        """获取上下文的统一接口"""
        if self.enhanced_context:
            try:
                return self.enhanced_context.build_context(novel_id, chapter_num)
            except Exception as e:
                if self.config["step2_enhanced_context"]["fallback_to_legacy"]:
                    return self.legacy.intelligent_context_selector.select_context(...)
                raise
        return self.legacy.intelligent_context_selector.select_context(...)
```

## 6. 风险与回退方案

### 6.1 风险矩阵

| 步骤 | 风险 | 概率 | 影响 | 缓解 |
|-----|-----|-----|-----|-----|
| Step 1 | 影响性能 | 低 | 低 | 只监控不干预 |
| Step 2 | 上下文质量下降 | 中 | 中 | 回退开关 |
| Step 3 | 生成质量下降 | 高 | 高 | 保留原Agent |

### 6.2 回退步骤

```
Step 1 回退:
1. 关闭 OPTIMIZATION_CONFIG["step1_narrative_monitor"]["enabled"]
2. 重启服务

Step 2 回退:
1. 关闭 OPTIMIZATION_CONFIG["step2_enhanced_context"]["enabled"]
2. 确认 ENABLE_ENHANCED_CONTEXT = False
3. 重启服务

Step 3 回退:
1. 关闭 OPTIMIZATION_CONFIG["step3_simplified_agents"]["enabled"]
2. 恢复原有Agent初始化
3. 重启服务
```
