# InkAI 测试指南

## 📋 测试概览

本指南提供了InkAI系统的完整测试方案，确保系统功能的完整性和稳定性。

## 🚀 快速开始

### 1. 快速测试（推荐首次使用）

```bash
python quick_test.py
```

这个脚本会快速验证系统的基本功能，包括：
- 基本模块导入
- 系统组件创建
- Flask应用启动
- 增强功能启用

**预期结果**: 所有测试通过，系统基础功能正常

### 2. 完整测试套件

```bash
python run_all_tests.py
```

这会运行所有测试模块并生成详细的测试报告。

## 🐛 常见问题解决

### 问题1: 导入错误
```
❌ 基本导入失败: No module named 'xxx'
```

**解决方案**:
```bash
pip install -r requirements.txt
```

### 问题2: 配置错误
```
❌ 配置加载失败: API_KEY not found
```

**解决方案**:
1. 检查config.py文件
2. 设置正确的环境变量
3. 验证API密钥有效性

### 问题3: 权限错误
```
❌ 数据管理器初始化失败: Permission denied
```

**解决方案**:
```bash
chmod 755 data/
chmod 644 data/novels/
```

### 问题4: 内存不足
```
⚠️ 内存使用增长过多: 25.0%
```

**解决方案**:
1. 关闭其他应用程序
2. 增加系统内存
3. 调整内存管理配置

### 问题5: API调用失败
```
❌ LLM调用失败: Connection error
```

**解决方案**:
1. 检查网络连接
2. 验证API密钥
3. 检查API服务状态
