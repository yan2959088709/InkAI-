# 性能优化模块集成设计文档

## 设计目标

在续写流程中集成性能优化模块，提升系统性能和响应速度。

## 性能优化模块列表

### 1. ParallelProcessor - 并行处理
- **用途**: 并行执行多个评估/改进任务
- **集成点**: 
  - 一致性评估（6个评估Agent并行执行）
  - 一致性改进（6个改进Agent并行执行）

### 2. IntelligentCacheManager - 智能缓存
- **用途**: 缓存评估结果、上下文选择结果、LLM响应
- **集成点**:
  - 上下文选择结果缓存
  - 评估结果缓存
  - LLM响应缓存

### 3. PerformanceMonitor - 性能监控
- **用途**: 监控系统性能，记录任务执行时间
- **集成点**:
  - 关键操作性能监控
  - LLM调用性能监控
  - 任务执行时间统计

### 4. BatchProcessor / LLMRequestBatcher - 批量处理
- **用途**: 批量处理LLM请求，减少API调用次数
- **集成点**:
  - LLM调用批量处理（可选，需要API支持）

## 集成方案

### 1. 并行处理集成

#### 一致性评估并行化
```python
# 原来：串行执行
for assessor in assessors:
    result = assessor.process(input_data)

# 优化后：并行执行
assessment_tasks = [
    {"task_id": "character", "assessor": assessor, "input": input_data}
    for assessor in assessors
]
results = parallel_processor.execute_parallel_assessment(assessment_tasks)
```

#### 一致性改进并行化
```python
# 原来：串行执行
for improver in improvers:
    result = improver.process(input_data)

# 优化后：并行执行
improvement_tasks = [
    {"task_id": "character", "improver": improver, "input": input_data}
    for improver in improvers
]
results = parallel_processor.execute_parallel_improvement(improvement_tasks)
```

### 2. 缓存集成

#### 上下文选择缓存
```python
# 检查缓存
cache_key = cache_manager.get_cache_key({
    "novel_id": novel_id,
    "chapter": current_chapter,
    "requirements": user_requirements
})
cached_context = cache_manager.get_context_cache(novel_id, current_chapter)

if cached_context:
    return cached_context

# 执行上下文选择
context = intelligent_context_selector.select_context(...)

# 保存缓存
cache_manager.set_context_cache(novel_id, current_chapter, context)
```

#### 评估结果缓存
```python
# 检查缓存
cache_key = cache_manager.get_cache_key({
    "content": content,
    "knowledge_base": knowledge_base,
    "type": assessment_type
})
cached_result = cache_manager.get_assessment_cache(cache_key)

if cached_result:
    return cached_result

# 执行评估
result = assessor.process(input_data)

# 保存缓存
cache_manager.set_assessment_cache(cache_key, result)
```

### 3. 性能监控集成

#### 任务性能监控
```python
# 记录任务开始
start_time = time.time()
performance_monitor.record_task_start("consistency_assessment")

# 执行任务
result = perform_assessment()

# 记录任务完成
execution_time = time.time() - start_time
performance_monitor.record_task("consistency_assessment", execution_time, success=True)
```

#### LLM调用性能监控
```python
# 记录LLM调用
start_time = time.time()
performance_monitor.record_llm_call_start()

# 执行LLM调用
response = llm_call()

# 记录LLM调用完成
response_time = time.time() - start_time
performance_monitor.record_llm_call(response_time, success=True, tokens_used=100)
```

### 4. 批量处理集成（可选）

如果LLM API支持批量请求，可以使用批量处理：
```python
# 收集多个LLM请求
requests = [
    {"messages": messages1, "callback": callback1},
    {"messages": messages2, "callback": callback2},
    ...
]

# 批量提交
request_ids = llm_batcher.submit_batch_requests(requests)

# 等待响应
responses = llm_batcher.wait_for_batch_responses(request_ids)
```

## 集成位置

### 1. `_perform_consistency_assessments()`
- 使用并行处理执行6个评估Agent
- 使用缓存存储评估结果
- 使用性能监控记录执行时间

### 2. `_perform_consistency_improvements()`
- 使用并行处理执行6个改进Agent
- 使用性能监控记录执行时间

### 3. `intelligent_context_selector.select_context()`
- 使用缓存存储上下文选择结果
- 使用性能监控记录执行时间

### 4. Agent的LLM调用
- 使用缓存存储LLM响应
- 使用性能监控记录LLM调用性能

## 性能提升预期

- **并行处理**: 6个评估任务从串行（~60秒）到并行（~15秒），提升约4倍
- **缓存**: 重复的上下文选择和评估可以立即返回，提升约10-100倍
- **性能监控**: 提供性能数据，帮助优化瓶颈
