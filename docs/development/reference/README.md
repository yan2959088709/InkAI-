# 开发参考文档目录

本目录存放开发过程中需要参考的核心文档，作为开发的"指向标"。

## 文档列表

### 1. 系统架构分析报告.md
- **用途**: 完整的系统架构分析，包含所有发现的问题和未实现功能
- **重要性**: ⭐⭐⭐⭐⭐ 核心参考文档
- **内容**:
  - Agent系统完整梳理
  - 核心系统模块分析
  - 工作流程调用链分析
  - 发现的主要问题
  - 深度挖掘：未实现功能详细清单

### 2. 深度分析-知识库和嵌入模型使用情况.md
- **用途**: 专门针对知识库和嵌入模型的深度分析
- **重要性**: ⭐⭐⭐⭐
- **内容**:
  - 核心知识库使用情况
  - 嵌入模型配置和使用情况
  - 动态知识库使用情况
  - 智能上下文选择器使用情况

### 3. 深度代码分析Prompt模板.md
- **用途**: 用于指导代码分析的Prompt模板
- **重要性**: ⭐⭐⭐
- **内容**:
  - 分析方法和技巧
  - 检查步骤和验证方法
  - 输出格式要求

## 使用说明

这些文档是开发过程中的**核心参考**，在进行任何重大决策前都应该查阅这些文档。

在进行代码清理和重构时，应该：
1. 参考"系统架构分析报告"了解所有问题
2. 参考"深度分析"了解具体模块的使用情况
3. 使用"Prompt模板"进行代码分析
