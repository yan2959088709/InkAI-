# 核心知识库架构设计文档

## 设计目标

### 核心要求
1. ✅ **双层架构**: 核心知识库（静态）+ 动态知识库（动态）
2. ✅ **支持动态更新**: 随着章节推进自动更新动态知识
3. ✅ **面向长篇小说**: 支持多章节、长文本、复杂关系
4. ✅ **测试驱动**: 每一步都要测试，测试通过才算完成

---

## 集成点设计

### 创作流程集成点

```
start_new_novel()
  └─> create_characters()
      └─> [NEW] initialize_core_knowledge(characters=...)
  └─> generate_storyline()
      └─> [NEW] update_core_knowledge(storyline=..., world_setting=...)
  └─> write_first_chapter()
      └─> [NEW] select_context()  # 使用智能上下文选择器
      └─> [NEW] update_after_chapter()  # 章节完成后更新动态知识
```

### 续写流程集成点

```
start_novel_continuation()
  └─> [NEW] get_core_knowledge()  # 获取核心知识
  └─> [NEW] get_dynamic_knowledge()  # 获取动态知识
  └─> generate_continuation_storyline()
      └─> [NEW] select_context()  # 使用智能上下文选择器
  └─> write_continuation_chapter()
      └─> [NEW] select_context()  # 使用智能上下文选择器
      └─> [NEW] update_after_chapter()  # 章节完成后更新动态知识
```

## 更新机制设计

### 自动更新触发器

```python
def update_dynamic_knowledge_after_chapter(novel_id: str, 
                                         chapter_number: int,
                                         chapter_content: Dict):
    """章节完成后的自动更新流程"""
    
    # 1. 生成章节摘要
    summary = generate_chapter_summary(chapter_content)
    
    # 2. 分析角色发展
    character_changes = analyze_character_development(
        chapter_content, 
        previous_knowledge
    )
    
    # 3. 提取关键事件
    key_events = extract_key_events(chapter_content)
    
    # 4. 检测新伏笔
    new_foreshadowing = detect_foreshadowing(chapter_content)
    
    # 5. 检测世界观变化
    world_changes = detect_world_changes(chapter_content)
    
    # 6. 分析关系发展
    relationship_changes = analyze_relationships(
        chapter_content,
        previous_knowledge
    )
    
    # 7. 更新动态知识库
    dynamic_knowledge_manager.update_after_chapter(
        novel_id=novel_id,
        chapter_number=chapter_number,
        chapter_content={
            "summary": summary,
            "character_changes": character_changes,
            "key_events": key_events,
            "new_foreshadowing": new_foreshadowing,
            "world_changes": world_changes,
            "relationship_changes": relationship_changes
        }
    )
```
