# 统一测试计划

## 测试目标

验证所有已实现功能的正常工作，包括：
1. 核心知识库在续写流程中的使用
2. 12个一致性Agent集成
3. 性能优化模块集成
4. 嵌入模型和RAG系统

## 测试原则

- 每一步都要测试，测试通过才算完成
- 优秀的开发不能在没有经历全方位的测试下，就说这是成功的
- 分步骤慢慢实现，解决所有报错

## 测试步骤

### 阶段1：基础功能测试
1. 测试嵌入模型服务（EmbeddingService）
   - 测试单个文本嵌入生成
   - 测试批量文本嵌入生成
   - 测试相似度计算
   - 测试错误处理

2. 测试向量数据库（VectorDatabase）
   - 测试向量添加
   - 测试向量检索
   - 测试向量删除
   - 测试持久化存储

### 阶段2：集成功能测试
3. 测试智能上下文选择器（语义搜索集成）
   - 测试语义搜索功能
   - 测试上下文选择（包含语义搜索结果）
   - 测试回退机制

4. 测试核心知识库集成
   - 测试核心知识库初始化
   - 测试核心知识库获取
   - 测试在续写流程中使用

5. 测试一致性Agent集成
   - 测试6个评估Agent
   - 测试6个改进Agent
   - 测试并行处理
   - 测试缓存机制

6. 测试性能优化模块
   - 测试并行处理
   - 测试缓存机制
   - 测试性能监控

### 阶段3：完整流程测试
7. 测试创作流程（包含核心知识库）
   - 测试标签选择
   - 测试角色创建（核心知识库初始化）
   - 测试故事线生成（核心知识库更新）
   - 测试第一章写作（向量数据库添加）

8. 测试续写流程（完整功能）
   - 测试续写故事线生成（核心知识库使用、语义搜索）
   - 测试续写章节写作（核心知识库使用、语义搜索）
   - 测试一致性评估（并行处理、缓存）
   - 测试一致性改进（并行处理）
   - 测试章节保存（向量数据库添加、动态知识库更新）

## 测试方法

- 单元测试：测试单个模块功能
- 集成测试：测试模块间协作
- 端到端测试：测试完整流程

## 预期结果

- 所有功能正常工作
- 无错误或异常
- 性能符合预期
- 数据正确存储和检索
