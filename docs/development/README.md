# 开发文档目录

本目录包含项目开发过程中的所有文档。

## 目录结构

```
docs/development/
├── README.md                    # 本文件
├── 开发计划.md                  # 详细开发计划
├── reference/                   # 开发参考文档（指向标）
│   ├── README.md
│   ├── 系统架构分析报告.md
│   ├── 深度分析-知识库和嵌入模型使用情况.md
│   └── 深度代码分析Prompt模板.md
├── reading/                     # 开发者阅读文档
│   ├── README.md
│   ├── README.md（项目主README）
│   ├── PROJECT_STRUCTURE.md
│   ├── TESTING_GUIDE.md
│   └── comprehensive_test_plan.md
└── logs/                        # 开发日志
    └── 开发日志.md
```

## 使用指南

### 开发参考文档（reference/）
**用途**: 开发过程中的核心参考，作为"指向标"
- 在进行重大决策前必须查阅
- 在进行代码清理时必须参考
- 在进行功能实现时必须了解

### 开发者阅读文档（reading/）
**用途**: 帮助开发者理解项目
- 新开发者入门必读
- 项目结构和测试指南
- 项目总体介绍

### 开发日志（logs/）
**用途**: 记录所有开发活动
- 所有代码修改
- 所有功能实现
- 所有决策记录
- 所有问题修复

## 快速开始

1. **新开发者**: 先阅读 `reading/` 目录下的文档
2. **开始开发**: 查阅 `reference/` 目录下的分析报告
3. **记录工作**: 在 `logs/开发日志.md` 中记录所有活动
4. **查看计划**: 查看 `开发计划.md` 了解整体规划
