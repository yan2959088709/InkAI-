## 1. 执行摘要

本文档详细描述InkAI小说生成系统架构优化的实施计划，基于Phase 1代码审计结果制定。

### 核心优化目标
1. **建立叙事推进状态监控中心** - 实时追踪剧情进展
2. **优化上下文管理** - 利用大模型长上下文能力
3. **简化生成架构** - 减少过度工程化

### 优化范围

| 类别 | 内容 |
|-----|------|
| 新增组件 | NarrativeStateMonitor (剧情状态监控中心) |
| 重构组件 | EnhancedContextBuilder (增强上下文构建器) |
| 保留组件 | VolumeManager, ForeshadowingLifecycleManager, DualLayerStorylineManager |
| 简化组件 | RhythmKeeper (集成到监控中心) |
| 合并组件 | 27个Agent → 2-3个核心Agent |

- 节奏控制 (20%): rhythm_consistency
- 阶段进展 (20%): phase_progress_alignment
- 连贯性 (20%): consistency_score
- 创新性 (15%): 1 - repetition_rate

### 公式
health = Σ(dimension_weight × dimension_score)
