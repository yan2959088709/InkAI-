## 1. 实验目标

### 1.1 核心假设

| 假设ID | 假设内容 | 验证方式 |
|-------|---------|---------|
| **H1** | 新架构 (NarrativeStateMonitor + EnhancedContextBuilder + SimplifiedWriterAgent) 的读者体验评分显著高于原架构 | A/B测试 |

```
主要指标:
- 读者体验评分: 新架构 > 原架构 + 0.5分 (5分制)
- 套路重复率: 新架构 < 原架构 - 10%
- 伏笔回收率: 新架构 > 原架构 + 15%

次要指标:
- 生成效率: 差异 < 20%
- 崩溃率: 新架构 < 5%
```

## 3. 评估指标

### 3.1 读者体验评分 (主观)

**评估维度:**

| 维度 | 问题 | 评分范围 |
|-----|-----|---------|
| 连贯性 | "这一章与前文衔接自然吗？" | 1-5 |
| 吸引力 | "这一章让你想继续看下去吗？" | 1-5 |
| 人物 | "人物行为符合性格吗？" | 1-5 |
| 新鲜感 | "这一章有重复之前套路的感觉吗？" (反向) | 1-5 |
| 整体 | "给这一章整体打分" | 1-5 |

**评估方式:**
- 盲评: 评审不知道章节是哪个架构生成的
- 每组随机抽取10章评估
- 5-10人评审团取平均分

### 3.3 伏笔回收率 (追踪)

**追踪指标:**

| 指标 | 计算方式 |
|-----|---------|
| 伏笔总数 | 埋下的伏笔总数 |
| 已回收数 | 被揭示的伏笔数 |
| 超时数 | 超过最佳回收期的伏笔数 |
| 回收率 | 已回收数 / 伏笔总数 |

**判定标准:**
- > 80%: 优秀
- 60-80%: 良好
- 40-60%: 一般
- < 40%: 差

| Token消耗 | 总输入+输出token数 |

## 5. 统计分析方法

### 5.1 假设检验

**H1: 读者体验评分**
```
配对t检验:
- 原假设 H0: 新架构评分 = 原架构评分
- 备择假设 H1: 新架构评分 ≠ 原架构评分
- 显著性水平: α = 0.05
```

**H2-H4: 其他指标**
```
独立样本t检验或Mann-Whitney U检验:
- 取决于数据分布
- 显著性水平: α = 0.05
```

### 5.2 效果量

| 效果量 | 定义 | 解释 |
|-------|-----|-----|
| Cohen's d < 0.2 | 微小 | 实际意义有限 |
| Cohen's d = 0.2-0.5 | 小 | 有限改进 |
| Cohen's d = 0.5-0.8 | 中 | 有意义改进 |
| Cohen's d > 0.8 | 大 | 显著改进 |

### B. 数据统计代码

```python
import scipy.stats as stats
import numpy as np

def analyze_results(new_scores, old_scores):
    """统计分析"""
    # t检验
    t_stat, p_value = stats.ttest_rel(new_scores, old_scores)

    # 效果量
    diff = np.mean(new_scores) - np.mean(old_scores)
    effect_size = diff / np.std(old_scores)

    # 结论
    significant = p_value < 0.05
    improvement = "显著提升" if significant and diff > 0 else "无显著差异或下降"

    return {
        "t_statistic": t_stat,
        "p_value": p_value,
        "effect_size": effect_size,
        "significant": significant,
        "conclusion": improvement
    }
```
